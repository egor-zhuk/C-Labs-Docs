#### Упражнение 3. Создание и использование элемента управления ToolStrip
В форму `Form4` добавлена панель инструментов `ToolStrip` с кнопками "New", "Cascade", "Tile". Реализована обработка нажатий на кнопки панели инструментов.

**Код:**
```csharp
private void toolStrip1_ItemClicked(object sender, ToolStripItemClickedEventArgs e)
{
    if (e.ClickedItem.Tag == null) return;

    switch (e.ClickedItem.Tag.ToString())
    {
        case "NewDoc":
            CreateNewDocument();
            break;
        case "Cascade":
            LayoutMdi(MdiLayout.Cascade);
            UpdateStatus("Windows is cascade");
            break;
        case "Title":
            LayoutMdi(MdiLayout.TileHorizontal);
            UpdateStatus("Windows is horizontal");
            break;
    }
}
```

#### Упражнение 9. Проверка вводимых значений. Элемент управления ErrorProvider
В форме `Form8` реализована валидация ввода в `TextBox` с использованием событий `KeyPress` и `Validating`. Для отображения ошибок используется компонент `ErrorProvider`.

**Код (`Form8.cs`):**
```csharp
private void textBox1_KeyPress(object sender, KeyPressEventArgs e)
{
    if (char.IsDigit(e.KeyChar))
    {
        e.Handled = true; 
        errorProvider1.SetError(textBox1, "Must be letter");
    }
    else
    {
        errorProvider1.SetError(textBox1, "");
    }
}
```
