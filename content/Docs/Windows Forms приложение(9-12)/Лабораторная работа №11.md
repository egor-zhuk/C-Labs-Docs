#### Упражнение 1. Создание составного элемента управления
Разработан составной элемент управления `UserControlTimer`, содержащий `Label` и `Timer`, отображающий текущее время.

**Код (`UserControlTimer.cs`):**
```csharp
public partial class UserControlTimer : UserControl
{
    // ...
    private void timer1_Tick(object sender, EventArgs e)
    {
        label1.Text = DateTime.Now.ToLongTimeString();
    }
    // ...
}
```

#### Упражнение 2. Создание специализированного элемента управления
Разработан элемент управления `UserControlTimer2`, наследуемый от `Control`. Отрисовка времени выполняется вручную в методе `OnPaint`.

**Код (`UserControlTimer2.cs`):**
```csharp
protected override void OnPaint(PaintEventArgs pe)
{
    base.OnPaint(pe);
    
    Graphics g = pe.Graphics;
    
    g.DrawString(DateTime.Now.ToLongTimeString(), Font, new SolidBrush(ForeColor), 0, 0);
}
```

#### Упражнение 3. Создание расширенных элементов управления
Создан элемент `ClickButton`, наследуемый от `Button`. Добавлено свойство `Clicks` для подсчета кликов, количество которых отображается на кнопке.

**Код (`ClickButton.cs`):**
```csharp
public class ClickButton : Button
{
    private int mClicks;
    // ...
    protected override void OnClick(EventArgs e)
    {
        mClicks++;
        base.OnClick(e);
    }

    protected override void OnPaint(PaintEventArgs pevent)
    {
        base.OnPaint(pevent);
        // ... отрисовка количества кликов ...
    }
}
```
