#### Упражнение 1. Настройка прямоугольной формы Windows
Создана форма `Form1`. Реализованы кнопки для изменения свойств формы: `FormBorderStyle`, `Size` (размер) и `Opacity` (прозрачность).

**Код:**
```csharp
private void Scene01_1()
{
    Text = "Trey Research";

    button1.Visible = true;
    button2.Visible = true;
    button3.Visible = true;

    button1.ForeColor = Color.Black;
    button1.Location = new Point(500, 150);
    button1.Size = new Size(500, 100);
    button1.Text = "Border Style";
    button1.Enabled = true;
    
    button2.Enabled = true;
    button2.Location = new Point(500, 300);
    button2.Size = new Size(500, 100);
    button2.Text = "Resize";
    
    button3.Enabled = true;
    button3.Visible = true;
    button3.Location = new Point(500, 450);
    button3.Size = new Size(500, 100);
    button3.Text = "Opacity";          
    
    FormBorderStyle = FormBorderStyle.Fixed3D;
    Opacity = 0.75;
}
```

#### Упражнение 3. Создание наследуемой формы
Создана дочерняя форма `Form3`, наследующая от `Form2` (диалоговой формы). В ней переопределена форма (также треугольная) и изменены элементы управления.

**Код (`Form3.cs`):**
```csharp
public partial class Form3 : Form2
{
    public Form3(int setter) : base(setter)
    {
        InitializeComponent();

        GraphicsPath myPath = new GraphicsPath();
        myPath.AddPolygon(new Point[] { new Point(Width/2, 0), new Point(Width, Height), new Point(0, Height) });
```
