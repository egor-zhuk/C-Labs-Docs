### Ход работы

#### Упражнение 1. Создание перечисления
Создано перечисление `AccountType` для представления типов банковских счетов (текущий и депозитный).

**Код:**
```csharp
public enum AccountType { Checking, Deposit }

AccountType goldAccount;
AccountType platinumAccount;
goldAccount = AccountType.Checking;
platinumAccount = AccountType.Deposit;
Console.WriteLine("The Customer Account Type is {0}", goldAccount);
Console.WriteLine("The Customer Account Type is {0}\n", platinumAccount);
```

#### Упражнение 2. Создание и использование структуры
Создана структура `BankAccount`, содержащая номер счета, баланс и тип счета.

**Код:**
```csharp
public struct BankAccount { public long accNo; public decimal accBal; public AccountType accType; }
```

#### Упражнение 3. Добавление возможности ввода/вывода
Реализован ввод данных для структуры `BankAccount` с консоли и вывод сводной информации.

**Код:**
```csharp
BankAccount silverAccount;
silverAccount.accType = AccountType.Checking;
silverAccount.accBal = (decimal)3200.00;
Console.Write("Enter account number: ");
silverAccount.accNo = long.Parse(Console.ReadLine());
Console.WriteLine("*** Account Summary ***");
Console.WriteLine("Acct Number {0}", silverAccount.accNo);
Console.WriteLine("Acct Type {0}", silverAccount.accType);
Console.WriteLine("Acct Balance ${0}", silverAccount.accBal);
```
