#### Упражнение 2. Проверка вводимого значения и использование массивов
Код оптимизирован с использованием массивов для хранения количества дней в месяцах и цикла `foreach`. Добавлена проверка корректности ввода.

**Код:**
```csharp
int[] DaysInMonths = new int[] { 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31 };
foreach (int daysInMonth in DaysInMonths)
{
    if (dayNum <= daysInMonth) break;
    else
    {
        dayNum -= daysInMonth;
        monthNum++;
    }
}
```

#### Упражнение 3. Учет високосных годов
Добавлена логика проверки високосного года и соответствующий массив дней для високосного года.

**Код:**
```csharp
bool isLeapYear = (yearNum % 4 == 0) && (yearNum % 100 != 0 || yearNum % 400 == 0);
if (isLeapYear)
{
	Console.WriteLine("{0} is a leap year", yearNum);
	Console.Write("Please enter a day number between 1 and 366: ");
}
else
{
	Console.WriteLine("{0} is NOT a leap year", yearNum);
	Console.Write("Please enter a day number between 1 and 365: ");
}
```
