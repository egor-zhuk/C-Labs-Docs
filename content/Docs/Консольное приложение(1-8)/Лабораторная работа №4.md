### Ход работы

#### Упражнение 1. Использование параметров в методах, возвращающих значения
Создан класс `Utils` и метод `Greater`, возвращающий большее из двух чисел.

**Код:**
```csharp
public static int Greater(int a, int b)
{
    if (a > b) return a;
    else return b;
}
```

#### Упражнение 2. Использование параметров, передаваемых по ссылке (`ref`)
Реализован метод `Swap` для обмена значениями двух переменных с использованием ключевого слова `ref`.

**Код:**
```csharp
public static void Swap(ref int a, ref int b)
{
    int temp = a;
    a = b;
    b = temp;
}
```
