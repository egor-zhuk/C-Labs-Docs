#### Упражнение 2. Обращение строки (Reverse)
Создан метод `Utils.Reverse` для инвертирования строки.

**Код:**
```csharp
public static void Reverse(ref string s)
{
    string sRev = "";
    for (int k = s.Length - 1; k >= 0; k--) sRev = sRev + s[k];
    s = sRev;
}
```

**Код:**
```csharp
public static void Display(object item)
{
    IPrintable ip = (item as IPrintable);
    if (ip != null) ip.Print();
    else Console.WriteLine(item.ToString());
}
```
